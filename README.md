# inchi-tests

The InChI conformance suite (TODO.v2/16): an oracle corpus recorded
from the IUPAC reference implementation, plus the gate contract every
InChI engine passes. Engines: [inchi-engine](https://github.com/asciichem/inchi-engine)
(Ruby reference) and [inchi-rs](https://github.com/asciichem/inchi-rs)
(Rust). MIT.
